# Apex Motorsport Manager 0.6.2.3

Projeto completo Godot 4.x para Linux. Abertura: importe `project.godot` pelo Godot 4.7.2, depois F5.

A 0.6.2.3 é uma **refatoração incremental** da 0.6.2.2; não redesenha os gráficos da pista. HUD: cartões mais legíveis nos cantos, painel superior dos pilotos, ranking estreito, minimapa e controle flutuante de pausa/velocidade.

Leituras: `CHANGELOG_0623.md`, `MAPA_MODULOS_0623.md`, `RELATORIO_0623.md`.

Teste estático: `python3 tests/test_0623_modularization_static.py`.
Teste no próprio Godot (Linux): `bash linux/validar_0623.sh`.

**Não misture arquivos da 0.6.2.3 com a 0.6.2.2 na mesma pasta.**
