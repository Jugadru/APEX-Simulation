# APEX v0.6.5.1 — Living Factory

Abra `project.godot` no Godot 4.7.2 e execute o projeto. Na gestão, escolha **Living Factory**.

Selecione CAR 01 ou CAR 02 para inspecionar peças. Remova para o estoque; use INVENTORY para instalar, substituir ou armazenar. A substituição devolve a peça antiga ao estoque. Complete os seis slots antes de iniciar uma corrida. Operações ficam bloqueadas durante sessões, inclusive em pausa.

Condição, integridade e uso anterior são explicitamente indisponíveis. Distância é registrada pela simulação a partir desta versão. O desempenho compartilhado original permanece inalterado.

Leia `RELATORIO_TECNICO_APEX_v0.6.5.1.md` para limites, evidências e migração. Documentos com números anteriores são históricos da base; o relatório 0.6.5.1 é a referência desta entrega. Não use manifests históricos para verificar o pacote atual.
