# Apex 0.6.3.1 — Leia primeiro

1. Extraia o ZIP completamente em uma pasta nova, sem sobrepor o projeto anterior.
2. Abra Godot 4.7.2 no Linux Mint, importe `project.godot` desta pasta.
3. Pressione **F5**. Seus controles, HUD, câmeras, circuitos procedurais e simulação seguem os mesmos.
4. Inicie uma corrida. Acesse **RÁDIO** e selecione **EQUIPE** para acompanhar piloto e engenheiro.
5. Para testar a regressão, execute `tests/core_0631_radio_engineer_smoke_test.gd` por `--headless --script`.

Arquivos `CHANGELOG_0631.md` e `RELATORIO_NATIVO_0631.md` detalham exatamente o que mudou e o que foi testado.

**Os arquivos externos de Assetto Corsa, Bahrain e os carros 2012 não estão incluídos**: são laboratórios separados, com licenças ainda não confirmadas para redistribuição.
