# APEX v0.6.2.8 — Como testar

1. Extraia o projeto em uma pasta **nova** no Linux.
2. Importe `project.godot` no Godot e execute com F5.
3. Compare Bahrain (areia/edifícios baixos), Sepang (verde tropical), Monaco (urbano) e Silverstone (verde temperado).
4. Alterne entre Diretor TV, Seguir e Livre; confira se a pista continua correta, os carros circulam normalmente e as placas não atravessam o asfalto.
5. Verifique o GP da China para confirmar que a IA de pneus continua com comportamento semelhante ao aprovado.

Para validação automatizada com Godot instalado: `bash linux/validar_0628.sh`.

**Sem Godot instalado no ambiente de criação, não é possível afirmar que a cena foi compilada ou renderizada.**
