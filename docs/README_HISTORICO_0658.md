# APEX Motorsport Manager v0.6.5.8 — Race State Optimization

Abra project.godot no **Godot 4.7.2** e pressione F5. Linux: linux/run_apex.sh (aceita GODOT_BIN). A alternativa Compatibility permanece disponível.

Estados compactos separam a apresentação dos históricos do motor. Progressão e faixa lateral recebem suavização antes do verificador de ocupação. Mapas ocultos/inalterados e 3D pausado evitam trabalho desnecessário; seleção e reentrada continuam atualizando. HUD, qualidade gráfica, regras esportivas, gestão e saves anteriores preservados.

**F8** abre o Performance Profiler 1.0, inicialmente desligado. Coletar, limpar e exportar continuam disponíveis; o nome de exportação user://apex_performance_0657.json identifica o formato existente. Tempos são inclusivos e não devem ser somados entre pai/filho.
