# Apex Motorsport Manager 0.6.2.4 — Projeto Godot completo

O projeto mantém a HUD da versão anterior e reorganiza o código de interface para preparar o próximo trabalho de câmeras.

## Abrir

1. Extraia esta pasta em um diretório próprio.
2. Use **Importar** no Gerenciador de Projetos Godot para abrir `project.godot`.
3. No Godot 4.7.2 pressione **F5** para jogar.
4. Caso necessário, execute `bash linux/validar_0624.sh` pelo terminal.

Leia `CHANGELOG_0624.md`, `RELATORIO_0624.md` e `MAPA_MODULOS_0624.md` para detalhes.

A verificação nativa no editor não foi executada na máquina de geração; qualquer erro do Godot deve ser reportado com arquivo e linha.
