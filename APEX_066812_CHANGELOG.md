# APEX Motorsport Manager v0.6.6.8.12 — Guia da Temporada 2012

## Uma funcionalidade principal: referência histórica integrada

- Guia no menu com abas PNEUS, CARROS E EQUIPES e CALENDÁRIO.
- Apresentação dos seis pneus Pirelli de 2012 usando o catálogo de pneus já existente, com cores e códigos históricos.
- 12 modelos de chassis históricos, fabricantes de motor V8, equipes e duplas de pilotos 2012, sem modelos 3D novos.
- 20 GPs, datas oficiais FIA, nomes das pistas, número de voltas e dois slicks nominados para cada GP no APEX.
- Botões para selecionar equipe/GP no menu com as rotinas existentes; indisponíveis para mudar a carreira já em curso.
- Correção da HUD: pneu macio amarelo, médio branco, duro prata e os demais conforme 2012.
- Novos arquivos de referência, GUI e teste; 20 scripts de CI configurados.
- Não altera RaceEngine, Replay, Core 2, IA, física, desgaste, regulamento, saves, retratos 8.11 ou modelos 3D.

Dependência de versão: branch derivada diretamente da v0.6.6.8.11, cujo PR ainda não foi mesclado. Integração sequencial recomendada, sem sobrescrever a main antes de homologar as pendências visuais.
